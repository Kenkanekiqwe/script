# Иконки Каптов

Разместите в этой папке иконки для каждого уровня капта:

## Требуемые файлы:
- level0.png - Иконка для уровня "Новички"
- level1.png - Иконка для уровня "Опытные"
- level2.png - Иконка для уровня "Ветераны"
- level3.png - Иконка для уровня "Элита"
- level4.png - Иконка для уровня "Легенды"
- level5.png - Иконка для уровня "Титаны"

## Рекомендации:
- Размер: 64x64 пикселей
- Формат: PNG с прозрачным фоном
- Стиль: Соответствующий общему дизайну интерфейса

## Примечание:
Если иконки отсутствуют, будет использоваться запасная иконка из img/svg/ticket_star.svg
(код в HTML: onerror="this.src='img/svg/ticket_star.svg'")
